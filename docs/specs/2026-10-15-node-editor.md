# 可编辑节点编辑器：在节点图里改参数并重出

- 状态：已确认（2026-10-15）
- 日期：2026-10-15
- 基于：Try-on MCP spec（`docs/specs/2026-10-15-mcp.md`，已完成并经真实冒烟）
- 不取代：Tryon Studio spec（studio 看板保留原样，本 spec 不涉及）

## 1. 背景与目标

MCP 阶段的节点图只能看。真实冒烟里出现了典型场景：4 张里 1 张被参考图上的模特脸带偏，需要把参考图上的脸裁掉，只重出这一张。现在只能回到对话里让 Agent 重裁、整款重跑，连带把没问题的那张也重出一遍。

目标：

1. 在节点图页面上直接修改一款的参考图、提示词、换装范围和模特图，点「重出」就开始，不经过 Agent。
2. 可以只重出选中的某几张，其余不动。
3. MCP 提供同样的能力，Agent 在对话里也能只重出一张、改提示词后重出，两边用同一套规则。

## 2. 页面与本地服务

- 节点图改为由本机服务提供的网页，只监听 `127.0.0.1`，不对局域网开放。
- 打开方式：`start_run` 与新的重出操作开始后自动在浏览器打开；也可以用 CLI 命令或 MCP 工具对任一素材根目录、任一 runId 打开。服务没在运行时由打开操作自动拉起。
- 服务退出后，run 目录里的 `graph.html` 仍可直接双击打开，作为只读页面使用（与 MCP 阶段一致）；页面上的编辑入口在只读模式下隐藏，并提示如何打开可编辑版本。
- 服务不自动退出，命令行 Ctrl+C 结束；正在进行的出图不受影响（出图仍在独立后台进程中）。
- 页面不需要登录；不存放、不显示任何密钥。

## 3. 编辑

编辑以「款」为单位，在节点图上该款所在的区域内完成。编辑在点「重出」之前只存在于页面里，不写任何文件（裁图除外，见 3.1）；刷新页面或离开时如有未重出的修改，提示会丢失。

### 3.1 参考图

- 显示这款当前使用的参考图（按顺序），每张可以：移除（只是本次不用，不删文件）、调整顺序、修改用途名。
- 可以从这款的服装原图和 `裁图/<款号>/` 里已有的裁图中添加。
- 可以在服装原图上拖框裁一张新的参考图，或对已有裁图重新拖框；保存时写入 `裁图/<款号>/`，规则与 `crop` 工具一致（同名替换需明确确认，替换前的旧裁图不保留）。
- 参考图数量上限与出图一致（默认 6，最多 10）；超过时不能点重出并给出原因。

### 3.2 提示词

- 显示这款本次将使用的提示词全文，可直接修改。
- 修改过的提示词旁标「已改」，可一键恢复为默认生成的提示词。
- 参考图的增删、换序、改用途名会让默认提示词随之变化：未改过提示词时自动跟随；改过时不自动覆盖，而是提示「参考图已变，提示词里的图号可能对不上」，由人决定是否恢复默认。

### 3.3 换装范围与模特图

- 每款可单独切换 `outfit` / `top`；切换后默认提示词随之变化，已改过的提示词按 3.2 的规则提示。
- 模特图列表来自这款的模特图目录，每张可勾选是否参与；新加入目录的模特图在页面刷新后出现。

### 3.4 选择要重出的图

- 每张图（每个模特图对应一张）有勾选框；一款内可全选。可以跨款勾选。
- 勾选的图按各自所在款的编辑结果重出；没勾选的不重出、不受影响。
- 新勾选的模特图（原 run 里没有）也可以出，相当于给这款加一张。

## 4. 重出

- 点「重出」后创建一个新的 run（新 runId），只包含勾选的图；新 run 的记录里写明它来自哪个 run，节点图页面显示「来自 <runId>」并可跳回。
- 新 run 的每款记录本次实际使用的参考图、提示词（标明是否人工修改）、换装范围、引擎，供以后对照。
- 开始后页面跳到新 run 的节点图，进度显示、状态文案、取消、心跳、中断判定与 MCP 阶段完全一致。
- 交付规则不变：写入 `成图/<款号>/`，同名加 `-v2`、`-v3`，从不覆盖。
- 同一素材根目录同一时间只允许一个出图在跑：已有出图在跑时「重出」按钮不可用，并显示正在跑的 runId 与跳转链接。
- 页面上提供「取消」按钮，行为与 `cancel_run` 一致。
- 引擎默认 `codex`；页面可选 `apimart`，选中时按钮旁显示「会产生真实费用」并要求二次确认；缺密钥时开始前报错。
- 人工修改过的提示词只用于这一次重出，不改变以后 `start_run` 的默认提示词。

## 5. MCP 对齐

- 新增工具 `rerun`：输入素材根目录、来源 runId、要重出的图（款号 + 模特图），以及每款可选的参考图列表（文件 + 用途名，按顺序）、提示词全文、换装范围、引擎。未给的项沿用来源 run 中这款的设置。返回与 `start_run` 相同（新 runId、run 目录、节点图地址、计划张数），并给出来源 runId。
- `run_status` 每款增加：本次使用的参考图列表、提示词全文及是否人工修改、换装范围；以便 Agent 在 `rerun` 前读到当前设置再改。
- 新增工具 `open_graph`：为指定素材根目录和 runId 打开可编辑节点图（必要时拉起本地服务），返回页面地址。
- 页面与 `rerun` 走同一套校验与执行逻辑：同样的输入在两边得到相同的计划与提示词。
- 工具说明里写明：只重出有问题的那几张；参考图带模特脸会把成图带偏，先用 `crop` 把脸裁掉再重出。
- CLI 增加对应的重出命令，供 MCP 与页面在后台调用；现有 `run` / `crop` / `studio` / `status` 行为不变。

## 6. Out of Scope

- 编辑后提示词、参考图选择持久化为这款以后的默认设置。
- 删除服装原图、裁图或成图文件；在页面里上传新的服装图或模特图（仍在文件夹里放）。
- 在页面上挑选、标记、移动 `成图/` 里的图（人在文件夹里定）。
- 自动质检、打分、自动重出（明确不做）。
- 同一素材根目录多个 run 并行或排队；已中断 run 的自动续跑。
- 局域网/远程访问、多人同时编辑同一页面。
- studio 看板的任何改动；通过页面启动全新的完整出图（仍用 `start_run`）。
- 修改默认提示词的出图规则与引擎行为。

## 7. 验收标准

全部用假引擎验证，真实引擎只做最后一条冒烟。

1. **只重出一张**：一个 2 款 4 张的已完成 run，在页面勾选 1 张点重出：新 run 只计划 1 张，完成后 `成图/<款号>/` 多出 1 个 `-v2` 文件，其余文件字节不变。
2. **参考图编辑**：移除、换序、改用途名、从原图添加后重出，新 run 记录与发给引擎的参考图顺序、数量与页面一致；被移除的裁图文件仍在。
3. **拖框裁图**：在页面拖框保存的裁图与用同样千分比框调 `crop` 工具得到的文件字节一致；同名替换未确认时不写文件。
4. **提示词**：修改后重出，引擎收到的提示词与页面文字完全一致，记录标为人工修改；未修改时与 `start_run` 默认生成的提示词一致；改过提示词后再改参考图会出现图号提示且不自动覆盖。
5. **换装范围与模特**：切换 `top` 后默认提示词与 `start_run --swap top` 一致；勾选原 run 没有的模特图可以出图。
6. **单占用**：出图进行中，页面重出按钮不可用并指向正在跑的 run；`rerun` 被拒绝并返回正在跑的 runId。
7. **取消**：页面「取消」与 `cancel_run` 结果一致（已交付保留、正在出的不进入 `成图/`、其余标为已取消）。
8. **来源追溯**：新 run 记录与页面显示来源 runId，可跳回；`list_runs` 中可看到来源关系。
9. **MCP 对齐**：同一份编辑分别经页面与 `rerun` 提交，两个新 run 的计划（款、模特、参考图、提示词、换装范围）完全一致；`run_status` 能读到每款当前设置。
10. **只读回退**：本地服务未运行时双击 `graph.html` 能看到完整状态且没有编辑入口；`open_graph` 能拉起服务并打开可编辑页面。
11. **服务生命周期**：只监听 `127.0.0.1`；服务不自动退出，进行中的出图不受影响。
12. **只读输入与不覆盖**：整个过程前后，素材根目录中除 `成图/`、`裁图/` 以外的文件字节不变；`成图/` 已有文件字节不变。
13. **无密钥泄漏**：用 apimart 假配置重出一次，页面、接口返回、`run.json`、日志中均不含密钥。
14. **真实冒烟**：在真实素材上，页面里把一款参考图的人脸裁掉并只重出 1 张（Codex），再在 Claude Code 里用 `rerun` 只重出 1 张；结果交用户目测。

## 8. 已定事项（2026-10-15 确认）

- 每次重出都新建一个 run，而不是追加到原 run 里（这样每个 run 的记录不会变，历史可追溯）。
- 人工改过的提示词只用于这一次重出，以后 `start_run` 仍用默认提示词。
- 页面上「移除参考图」只是本次不用，不删 `裁图/` 里的文件。
