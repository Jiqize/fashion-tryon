# 页面放图与新建出图：在节点图里完成从素材到出图

- 状态：已确认（2026-10-15）
- 日期：2026-10-15
- 基于：可编辑节点编辑器 spec（`docs/specs/2026-10-15-node-editor.md`，已完成并经真实冒烟）
- 不取代：文件夹仍是唯一事实来源，页面只是往文件夹里放文件的另一种方式

## 1. 背景与目标

节点编辑器上线后，出图之后的修改与重出可以在页面里完成，但出图之前的步骤仍然要离开页面：

- 素材必须先在 Finder 里按 `<款号>/服装/`、`<款号>/模特/` 的目录结构放好，要记住结构、手工拖文件。
- 新出一款只能回到对话让 Agent 调 `start_run`，或敲命令。
- 编辑面板靠 ↑↓、加入、移除等文字按钮操作，参考图多时又长又挤，模特图被挤到最下面。

目标：

1. 把电脑里的图直接拖进节点图页面（或用文件选择框选），页面替人放进正确的文件夹。
2. 在节点图页面里新建款、选图、点「出图」，不经过 Agent。
3. 编辑面板改用拖拽和点图操作，减少文字按钮。
4. 同事仍可以直接在 Finder 里整理素材，两种方式放进去的图在页面里没有区别。

## 2. 打开页面

- 素材根目录还没有任何 run 时也能打开节点图页面，显示「素材」视图（见第 3 节），不再报错或空白。
- 有 run 时打开行为不变（默认到最近一次 run）；页面顶部固定有「素材」入口，随时可从任一 run 页面切过去。
- `open_graph` 与 CLI `editor` 在不指定 runId 时打开该素材根目录的页面（有 run 到最近一次，无 run 到素材视图）。
- 一个页面只对应一个素材根目录；切换素材根目录不在页面里做。

## 3. 素材视图

- 按款列出该素材根目录下所有款，每款显示服装图、模特图缩略图及数量；数据与 `scan` 一致。
- 页面每次进入素材视图或点「刷新」时重新扫描，Finder 里新放的图会出现。
- 「新建款」：填写款号后出现这款的空白卡片，可立即往里放图；款号不能为空；不能含 `/`、`\`、`_` 或空格（扫描按第一个 `_` 或空格截取款号，含这两个字符的款号刷新后会对不上）；不能以 `.` 开头；不能是 `成图`、`裁图`、`_runs` 或角色目录名（服装、模特等）；不超过 64 个字符；不能与已有款号重复（不区分大小写）。没放任何图的新款不写入文件夹，刷新后消失。

### 3.1 放图

- 每款卡片有「服装图」「模特图」两个放置区；可以把文件从 Finder / 桌面拖进去，也可以点放置区用文件选择框多选。
- 拖进来的文件写入这款对应的目录：
  - 素材根目录已有款时，沿用它现有的目录结构（按款分目录或按角色分目录，与 `scan` 支持的两种一致）；新根目录默认按款分目录 `<款号>/服装/`、`<款号>/模特/`。
  - 文件名保留原名；目录里已有同名文件时自动加后缀 `(2)`、`(3)`，从不覆盖。
- 支持 jpg / jpeg / png / webp；其它格式（含 heic、gif、pdf）不写入，并逐个说明哪些文件没放进去及原因。单个文件超过 50 MB 不写入。
- 一次拖多张时逐张写入，单张失败不影响其它张；全部结束后列出成功与失败。
- 放图后这款卡片立即刷新，不需要手工刷新。
- 页面不提供删除素材文件的功能；放错了在 Finder 里删，页面刷新后消失。

## 4. 新建出图

- 素材视图里每款可勾选参与本次出图，款内可勾选模特图（默认全选）；跨款勾选后底部条显示「出图 N 张」。
- 每款可在出图前展开编辑面板，改参考图、提示词、换装范围，规则与节点编辑器 spec 3.1–3.3 一致；未编辑的款按 `start_run` 的默认规则选参考图、生成提示词（有裁图优先用裁图，取前 N 张）。
- 点「出图」后新建一个 run：
  - 与 `start_run` 等价：记录、交付、进度、取消、心跳、单占用、引擎选择与费用确认都与现有规则一致。
  - 新 run 没有来源 run，页面不显示「来自」。
  - 开始后页面跳到新 run 的节点图。
- 没有服装图或没有勾选模特图的款不能参与，底部条说明原因。
- 同一素材根目录已有出图在跑时「出图」按钮不可用，并显示正在跑的 runId 与跳转链接（与重出一致）。

## 5. 编辑面板改进（素材视图与 run 页面共用）

- 参考图：拖动缩略图调整顺序；从「可添加」区把图拖进参考图列表即加入，拖出列表或点缩略图上的 × 即移除。保留键盘可用的排序方式（不只能用鼠标）。
- 参考图上的「拖框」「移除」改为鼠标移上去时出现的小图标，用途名仍可直接改。
- 可添加区（服装原图、裁图）默认展开为一行横向缩略图，不再需要先展开「添加参考图」。
- 模特图：点缩略图即选中 / 取消，选中有明显标记；模特图区放在面板上方，不需要滚动到底才能看到。
- 面板内容与行为（可改项、校验、提示词跟随规则）与节点编辑器 spec 一致，只改操作方式与布局。

## 6. MCP 与 CLI

- 不新增 MCP 工具；`start_run` 行为不变。页面出图与 `start_run` 走同一套执行逻辑。
- `open_graph` 的 runId 改为可选（见第 2 节）。
- 工具说明补一句：用户想自己放图、挑图时，用 `open_graph` 打开页面，不必在对话里一张张传。

## 7. Out of Scope

- 从淘宝、1688 等商品链接抓图；从剪贴板粘贴图片。
- 在页面里删除、重命名、移动素材文件或整个款；修改已有款号。
- 在页面里切换或新建素材根目录。
- heic 等格式的自动转换。
- 图片压缩、去背景、自动裁图、自动识别款号或用途。
- 自动质检、打分、自动重出（明确不做）。
- 多 run 并行或排队；局域网 / 远程访问；多人同时编辑。
- studio 看板的任何改动。

## 8. 验收标准

全部用假引擎验证，真实引擎只做最后一条冒烟。

1. **无 run 也能打开**：对一个只有素材、没有 `成图/` 的根目录打开页面，显示素材视图，款与图的数量与 `scan` 一致。
2. **拖进来放对位置**：分别在按款分目录、按角色分目录、全新空目录三种根目录里，往已有款与新建款拖入服装图和模特图，文件出现在 `scan` 能识别的对应目录，字节与源文件一致，`scan` 结果包含它们。
3. **不覆盖**：拖入与已有文件同名的图，旧文件字节不变，新文件带 `(2)` 后缀。
4. **格式与大小**：一次拖入 jpg、png、webp、heic、gif 和一张超过 50 MB 的 jpg，只有前三种写入，页面逐个列出未写入的文件和原因。
5. **Finder 与页面一致**：在 Finder 里往某款放一张模特图后点刷新，页面出现这张图，与页面拖入的图一样可勾选出图。
6. **新建出图等价 start_run**：同一份素材、同样勾选，用页面出图与 `start_run` 各跑一次，两个 run 的计划（款、模特、参考图、提示词、换装范围）完全一致。
7. **出图前编辑**：在素材视图改参考图顺序与提示词后出图，新 run 记录与发给引擎的内容与页面一致。
8. **拖拽操作**：拖动排序、拖入加入、× 移除后的参考图顺序与原按钮操作得到的结果一致；不用鼠标也能完成排序。
9. **点图选模特**：点击模特缩略图切换选中，底部条张数随之变化。
10. **单占用**：出图进行中，素材视图「出图」不可用并指向正在跑的 run。
11. **只写该写的地方**：整个过程前后，素材根目录里除新放入的文件、`成图/`、`裁图/` 外其它文件字节不变。
12. **安全**：上传接口只接受本页面的请求（与现有编辑接口同样的鉴权与来源校验）；文件名含 `../`、绝对路径或款号含路径字符时拒绝，不会写到素材根目录外。
13. **真实冒烟**：新建一个空素材根目录，在页面里新建 1 款、拖入服装图和 1 张模特图，用 Codex 出 1 张；结果交用户目测。

## 9. 已定事项（2026-10-15 确认）

- 只收 jpg / jpeg / png / webp，单张不超过 50 MB；heic 等提示放不进去，不自动转换。
- 页面出图默认引擎 `codex`，可选 `apimart`，选中时提示费用并二次确认（与重出一致）。
- 页面里不能删除素材，放错了在 Finder 里删。
- 「新建款」只建在当前素材根目录下。
