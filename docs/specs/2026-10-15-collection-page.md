# 合集页：一款一组，放图与节点两种模式

- 状态：已确认（2026-10-15）
- 日期：2026-10-15
- 基于：页面放图与新建出图 spec（`docs/specs/2026-10-15-page-upload-new-run.md`，已完成并经真实冒烟）、成图汇总（`4a3880e`）、缩略图服务（`94d63dc`）
- 原型：`docs/prototypes/2026-10-15-collection-page.html`（示例数据，只演示交互）
- 不取代：文件夹仍是唯一事实来源；页面往素材目录放图，衣服图、模特图、成图可删除（移到 `成图/_runs/已删除/`，可撤销），不改名

## 1. 背景与目标

素材页已经能放图、出图、看成图，但仍有几处不顺：

- 素材页是一长串卡片，看不出「哪些衣服配哪个模特、出了哪几版」，要跳到每次 run 的节点图才看得到；每次出图一张节点图，越用越分散。
- 只有一种出图方式：一款的衣服图当作同一套，换到每张模特身上。实际还会遇到「一个模特试很多件单品」和「两边一张对一张」的情况。
- 不满意的图要回到各次 run 的节点图逐张重出；被截掉的腿部这类问题只能靠手改提示词。

目标：

1. 把素材页改成「合集页」：一款一组，左边衣服、右边模特，参考 BOOM NOIR MAID 的分组结构，视觉保持现有极简风格。
2. 同一页面两种模式：「放图」整理素材，「节点」按款看衣服 → 设置 → 模特 → 成图版本的全貌。
3. 每款可选三种搭配规则，覆盖固定服装（主力）、固定模特、一对一。
4. 把审核后的优化建议并进来：待重出清单、保持画幅、半身标记、上传进度、出图进度、搜索与折叠、恢复默认。

## 2. 页面与入口

- 合集页取代素材页，地址仍是 `/materials/`；`open_graph`、CLI `editor` 在不指定 runId 时打开合集页（不再按「有没有 run」区分）。
- 每次 run 的节点图页面保留，作为「出图记录」：从合集页的出图进度、成图对照里进入；run 页面顶部「素材」入口改名「合集」。
- 顶栏固定显示：素材目录名与款数、模式切换（放图 / 节点）、搜索款号、出图进度、刷新、新建款。
- 底栏固定显示：已选几款、共出几张、统一换装范围、全部保持画幅、引擎、待重出（带数量）、出图。
- 模式选择在本浏览器里记住；默认「放图」。

## 3. 款（组）

- 一款一组，组仍由文件夹扫描得到（两种目录结构照旧）；页面里新建的款放图后才写入文件夹。
- 每组头部：勾选参与出图、序号、款号、素材张数与将出张数、换装范围、保持画幅、搭配规则、编辑（改过显示「已改」）、只出这款、上移 / 下移、折叠。
- 搜索按款号过滤（不区分大小写）；折叠状态在本浏览器里记住。
- 组默认按款号排序；可拖动组或用上移 / 下移调整顺序，调整后的顺序按素材目录保存，新出现的款排在最后；顶栏可一键恢复按款号排序。

### 3.1 搭配规则

每款选一种，默认「固定服装」。左边是这款的衣服图，右边是这款选中的模特图：

| 规则 | 左边的含义 | 生成哪些 | 例子 |
|---|---|---|---|
| 固定服装 | 同一套衣服的多张参考图 | 每个选中的模特 × 整套参考图，各 1 张 | 左 ABCD、右 EFG → E、F、G 各换上 ABCD，3 张 |
| 固定模特 | 多件不同的单品，每张图一件 | 每张选中的衣服图 × 唯一选中的模特，各 1 张 | 左 A–G、右 X → AX、BX…GX，7 张 |
| 一对一 | 与右边按顺序配对 | 第 n 张衣服图 × 第 n 张选中的模特图 | 左 ABC、右 EFG → AE、BF、CG，3 张 |

- 固定服装：参考图规则与现在一致（有裁图用裁图，取前 6 张，可在编辑里排序、增删）。
- 固定模特、一对一：每件衣服（左边一张图）出图时只用一张参考图——原图或它的一张裁图。裁过的默认用裁图；有多张裁图时在编辑里选用哪张，也可改回原图。左边每张衣服图可单独勾选是否参与。
- 固定模特下右边必须正好选中 1 个模特；选中 0 个或多于 1 个时这款不能出图，页面直接提示「固定模特只能选 1 个模特」（防止多拖进一张图导致批量出错）。
- 一对一两边张数不同时，多出的图标「未配对」，不出图，不阻止其它配对出图。
- 搭配规则、保持画幅、模特图的半身标记按素材目录保存，重新打开页面仍在；保存位置在 `成图/_runs/` 下，不写进素材文件夹。

### 3.2 成图命名

- 固定服装：`成图/<款号>/<模特图名>.png`，重出加 `-v2`、`-v3`（与现在相同）。
- 固定模特、一对一：`成图/<款号>/<衣服图名>-<模特图名>.png`，重出同样加版本后缀。
- 一律不覆盖已有文件。

## 4. 放图模式

- 每组一张卡片，左栏「衣服」、右栏「模特」，各自显示缩略图和一个放置区；拖图或点击选择放入，规则沿用上一版（格式、50 MB、同名加后缀、沿用目录结构）。
- 放图时在对应栏里显示进度「正在放入 x / y」与进度条；放图过程中仍可勾选、编辑其它内容，只有「出图」要等放完。
- 点模特缩略图切换选中；固定模特、一对一下，点衣服缩略图也切换选中；默认全选。
- 模特缩略图可标「半身」（被截掉的部位不补画，见第 6 节）。
- 衣服栏有「裁图」入口（三种规则都可用）；裁图在衣服栏、模特栏下面单独一排（成图上面，带「裁」标记，默认按文件名、可拖动排序，固定服装的默认参考图按这个顺序），出图实际用的参考图（原图或裁图）描绿边；裁图不会自动生成。
- 衣服图、模特图、成图悬停时左上角 × 删除：移到 `成图/_runs/已删除/<款号>/`，toast 可撤销；出图中不能删。衣服图连同由它裁出的裁图；成图只删当前版本并移出待重出。
- 衣服图、模特图可在栏内拖动排序，按素材目录保存在 `collection.json` 的 `itemOrder`；一对一按这个顺序配对，固定模特按这个顺序出图；页面出图与 MCP `start_run` 一致。
- 卡片底部一行显示这款每个出图组合的最新成图，带版本号，比素材缩略图大一档；生成中的显示「生成中」；点开见第 7 节对照。
- 没放图的新款显示两个大放置区，提示「新款，放图后写入文件夹」。

## 5. 节点模式

- 每组一条横向流程：衣服节点 → 设置节点 → 每个出图组合一行（模特或「衣服 + 模特」节点 → 成图节点）。
- 衣服节点显示前几张缩略图与总数，可往上拖图放入。
- 设置节点显示：换装范围、搭配规则、参考图张数（含裁图时注明）、提示词默认 / 已改、画幅。
- 点衣服节点或设置节点打开编辑抽屉（第 6 节）。
- 点模特节点切换这一行出不出；不出的行变淡。
- 成图节点横向列出历次版本（v1、v2…），最新的最大；生成中、排队、失败分别标出；每行有「＋待重出」。
- 版本来自 `成图/<款号>/` 里的文件与出图记录；在 Finder 里手放的成图也显示，但没有出图记录时不提供「出图记录」入口。

## 6. 编辑抽屉

- 右侧滑出，两种模式共用；内容：参考图（固定服装：拖动排序、拖出移除；固定模特、一对一：每件衣服选用原图或哪张裁图）、换装范围、搭配规则、保持画幅、提示词（仅固定服装；固定模特、一对一要逐张调整时用待重出备注）、恢复默认。各组的换装范围只在本页生效，不保存。
- 「保持画幅」：在提示词末尾追加一句固定要求「保持图1的取景范围，被截掉、没拍到的身体部位不要补画」；不做任何自动检测。标了「半身」的模特图出图时总是加这句，从 run 节点图重出、待重出重出时按当前半身标记补上。
- 提示词跟随规则沿用上一版：没改过时随参考图、范围、画幅变化自动更新；改过后只提示「图号可能对不上」。
- 编辑在出图前只存在页面里；关闭页面前有未出图的编辑时提示（与现在一致）。

## 7. 成图对照与待重出

- 双击成图（或点悬停的「对照」）打开对照：左服装图（实际用的参考图，固定服装全部列出）、中成图、右模特图；可切换版本；按钮「加入待重出」「出图记录」「关闭」；已在待重出时按钮为「移出待重出」，点了移出。
- 待重出清单跨款收集，每项显示款号、模特（和衣服）、版本，可填一行备注，可移除；清单按素材目录保存，重新打开仍在。
- 「重出这 N 张」：每张按产出它的那次出图的参考图、范围、提示词重出，备注追加到提示词末尾；N 张合成一次新的出图；提交后清单清空。
- 有出图在跑时「重出这 N 张」与「出图」一样不可用。

## 8. 出图

- 底栏「出图」按勾选的款、各款的搭配规则与选中项计算张数，一次提交为一次新的出图；「只出这款」只提交该款。
- 统一换装范围、全部保持画幅作用于本次勾选的所有款，不改各款保存的设置。
- 出图进度显示在顶栏「正在出图 x / y」，点开到这次的出图记录；结束后自动刷新成图。
- 同一时间仍只允许一次出图（锁）；apimart 仍需确认费用。

## 9. MCP 与 CLI

- `start_run` 按各款保存的搭配规则与保持画幅出图；从没在页面设置过的款按固定服装，与现在完全一致。
- `rerun`、`list_runs`、`run_status`、`cancel_run` 行为不变；run 节点图能显示固定模特、一对一的出图组合（显示衣服 + 模特）。
- 不新增 MCP 工具。

## 10. Out of Scope

- 重命名、移动素材或成图；修改已有款号。
- 任何自动质检、自动评分、自动判断要不要重出、自动识别半身。
- 自动裁图；固定模特、一对一下一件衣服用多张参考图。
- 一款同时用多种搭配规则；跨款组合（A 款衣服配 B 款模特）。
- 多人同时编辑同一素材目录的冲突处理。
- studio 看板的任何改动。

## 11. 验收标准

1. 打开 `fashion-tryon editor <根目录>` 或 `open_graph`（不带 runId）进入合集页；放图 / 节点切换后刷新页面仍是上次的模式。
2. 放图模式每款左衣服、右模特；拖图放入后卡片立即更新，放图中显示进度，放完前其它操作不被锁住。
3. 固定服装下勾选 2 个模特 → 出图 2 张，参考图与提示词与现在 `start_run` 默认相同。
4. 固定模特下左 3 张衣服、右选 1 个模特 → 出图 3 张，每张只用一张参考图（裁过的用裁图），成图命名为 `<衣服图名>-<模特图名>.png`；右边选 2 个模特时这款不能出图并提示「固定模特只能选 1 个模特」。
5. 一对一下左 3 张、右选 2 张 → 出图 2 张（前两对），第 3 张衣服图标「未配对」。
6. 搭配规则、保持画幅、半身标记关掉页面再打开仍在；`start_run` 按保存的规则出图；从未设置的款与现在结果一致。
7. 开「保持画幅」或标「半身」后，出图提示词末尾含那句固定要求；关掉后不含。
8. 节点模式每个出图组合一行，显示历次版本；生成中、失败有标记；Finder 里手放的成图也显示。
9. 成图对照可切换版本；加入待重出后清单数量 +1，关掉页面再打开仍在；「重出这 N 张」生成一次新出图，备注出现在对应提示词末尾，提交后清单清空。
10. 搜索款号只显示匹配的款；折叠状态刷新后保留；拖动调整组顺序后重新打开仍是该顺序，「按款号排序」可恢复。
11. 编辑抽屉「恢复默认」把参考图、提示词恢复到默认，搭配规则与范围不变；有未出图编辑时离开页面提示，只勾选不提示。
12. 有出图在跑时「出图」「重出这 N 张」不可用，顶栏显示进度 x / y 并能进入出图记录。
13. 页面除删除衣服图、模特图、成图（移到回收目录、可撤销）外不删除、不改名、不覆盖素材目录里任何已有文件；鉴权、Origin、CSP、密钥不外泄沿用上一版且有测试。
14. 真实冒烟：在冒烟目录用固定服装和固定模特各出 1 张（Codex），成图交用户目测，不做自动评价。

## 12. 已定事项（2026-10-15 确认）

- 合集页是主入口，run 节点图保留为出图记录。
- 待重出备注追加到提示词末尾。
- 「保持画幅」只在提示词里加一句要求，不引入检测。
- 三种搭配规则都要，固定服装为默认和主力。
- 固定模特只允许 1 个模特，多选时报错不出图。
- 固定模特、一对一也能裁图，每件衣服用原图或一张裁图。
- 组顺序默认按款号，也可手动调整并保存。
