# 前端交互升级：合集页与 run 节点图

- 状态：已确认（2026-10-16，用户点过原型后确认）
- 日期：2026-10-16
- 基于：合集页 spec（`docs/specs/2026-10-15-collection-page.md`，已完成、经真实冒烟与 Fable 审核修复 `40143ea`）
- 原型：`docs/prototypes/2026-10-16-frontend-interaction.html`（示例数据，只演示交互；缩略图在本地 `docs/prototypes/img/`，不入库）
- 交互参照：一份内部单文件 HTML 原型，只借交互方式，不借视觉风格
- 不取代：合集页 spec 的全部业务规则（搭配规则、命名、待重出、保持画幅、半身）照旧；本 spec 只改「怎么操作」

## 1. 背景与目标

合集页功能已齐，配色与版式可以接受，但操作方式偏老：

- 设置项大多是原生下拉菜单和复选框（搭配规则、换装范围、引擎、统一范围、保持画幅、每件衣服用哪张参考图）。
- 提示与确认用浏览器自带的 `alert` / `confirm`，报错是一行红字挤在底栏里。
- 款的顺序只能一步步点上移 / 下移；弹层不能按 Esc 关；没有键盘操作。
- 出图进度只在节点图页面看得全，合集页里不能中途停止。

目标：

1. 换成接近 macOS 新版系统的交互：开关、分段控件、弹出菜单、工作表式确认、toast、快速预览、拖动排序。
2. 合集页与 run 节点图用同一套控件，操作习惯一致。
3. 配色、字体、整体版式不变；技术上仍是无构建的原生 JS，同事包结构不变。
4. 顺手解决 Fable 审核里留给前端的两条：设置保存的先后顺序、上传中往同款另一栏放图。

## 2. 控件规则（两页通用）

| 原来 | 改成 | 用在 |
|---|---|---|
| 设置类复选框（开 / 关） | 开关（滑块式，点或按空格切换） | 保持画幅、全部保持画幅、抽屉里的保持画幅 |
| 选项 ≤ 4 个的下拉菜单 / 单选 | 分段控件 | 搭配规则（带图标）、换装范围、底栏统一换装范围、引擎、放图 / 节点模式 |
| 选项多或带图的下拉菜单 | 弹出菜单（点开在控件下方，带缩略图） | 固定模特、一对一下每件衣服用哪张参考图（原图 / 各张裁图） |
| `confirm` | 工作表式确认（从顶部落下，页面变暗，回车确认（焦点在「取消」上时回车 = 取消）、Esc 取消） | apimart 费用确认、替换同用途裁图、离开时有未出图编辑之外的所有确认 |
| `alert` 与底栏红字 | toast（右下角堆叠，成功 3 秒自动消失，出错停留到点关闭） | 放图成功 / 失败、保存失败、出图已开始、待重出操作结果 |
| 上移 / 下移按钮 | 拖动组头排序，组头右键（或「…」菜单）里保留「移到最前 / 最后」 | 合集页款顺序 |

- 离开页面时「有未出图编辑」的提示仍用浏览器原生离开提示（浏览器不允许自定义）。
- 所有控件可用键盘操作：Tab 能到，空格 / 回车能切换，焦点有清楚的高亮。
- 所有控件的显示文字与现在一致（「固定服装」「只换上衣」「保持画幅」等），不改业务用词。

## 3. 动效

- 统一缓动：快出慢停；悬停、按下、开关切换 0.2–0.3 秒；抽屉、弹出菜单、工作表 0.3–0.4 秒；toast 滑入 0.3 秒。
- 按下按钮有轻微下沉反馈；拖动时被拖的项半透明，落点处出现插入线。
- 系统开了「减少动态效果」时，所有过渡与动画关闭，只保留状态变化本身。
- 不做装饰性动画（粒子、漂浮、呼吸灯之类）。

## 4. 合集页

### 4.1 顶栏

- 左：素材目录名与款数、「最近一次出图」链接。
- 中：放图 / 节点分段控件。
- 右：搜索框（⌘F 聚焦，Esc 清空并失焦）、按款号排序、刷新、新建款（输入框 + 按钮，回车提交）。
- 新增缩略图大小滑块（小 / 中 / 大连续可调），只影响本页缩略图显示大小，本浏览器记住。

### 4.2 组头

- 勾选「选这款出图」保持复选框，样式改成圆角方框。
- 搭配规则、换装范围改成分段控件；保持画幅改成开关。
- 「编辑」按钮显示状态：设置改过时显示「编辑 · 已改」；人改过提示词而参考图又变了时显示黄色「提示词可能对不上」。
- 「只出这款」保留按钮。
- 组头可拖动排序（拖动把手在序号处）；「…」菜单含：移到最前、移到最后、折叠 / 展开。
- 折叠后组头下方显示一行摘要：衣服 N · 模特 已选/共 · 将出 N 张 · 成图 N 版。

### 4.3 放图模式

- 衣服栏、模特栏是拖放区：拖文件进来时整栏高亮、轻微上浮；末尾「＋」格可点可拖。
- 上传中往同一款的另一栏放图不再被忽略：排队，前一批放完后接着放，并在该栏显示「排队中」。
- 模特图点一下切换选中（保持现有规则）；选中、半身标记的状态变化有过渡。
- 缩略图悬停出现快捷操作：模特图「半身」，成图「预览」「加入待重出」。
- 选中任意缩略图后按空格：快速预览大图（再按空格或 Esc 关闭，← / → 切换同一栏的上一张 / 下一张）。

### 4.4 节点模式

- 衣服 → 设置 → 模特 → 成图版本的连线与布局不变。
- 设置节点里的规则、范围、画幅改用同样的分段控件 / 开关，可直接在节点上改，不必开抽屉。
- 成图版本节点支持悬停「预览」「加入待重出」，与放图模式一致。

### 4.5 编辑抽屉

- 从右侧滑出，打开时页面其余部分仍可滚动查看；Esc 或点抽屉外关闭。
- 搭配规则、范围、保持画幅用分段控件 / 开关；固定服装的参考图拖动排序、拖出移除照旧。
- 固定模特、一对一：每件衣服一行「衣服缩略图 → 当前参考图缩略图」，点参考图弹出菜单，列出原图与各张裁图的缩略图，点选即换。
- 「恢复默认」点击后先出工作表确认。

### 4.6 底栏

- 左：已选 N 款 · 出图 N 张。
- 中：统一换装范围分段控件（按各款设置 / 全部换整套 / 全部只换上衣）、全部保持画幅开关、引擎分段控件（codex / apimart）。
- 右：待重出（带数量）、出图主按钮。
- 出图中：主按钮变成进度（「出图中 3/10」+ 细进度条），旁边出现「停止」（调用现有取消接口，先工作表确认）。出图结束后 toast 汇总「交付 N 张 / 失败 N 张」，并给出「查看出图记录」链接。
- 键盘：⌘↩ 出图（与点按钮相同，含 apimart 确认）。

### 4.7 成图对照与待重出

- 成图对照仍是「原模特图 / 衣服参考图 / 成图」三图；版本切换改成分段控件，← / → 切换版本；Esc 关闭。
- 待重出清单改成右侧面板（与抽屉同位置，二者互斥）；每项一行：成图缩略图、款号与模特图名、备注输入框（失焦保存）、移除。
- 移除后 toast 提供「撤销」，5 秒内可恢复。
- 「重出这 N 张」在清单底部，apimart 时出工作表确认。

### 4.8 保存与一致性

- 组设置（规则、画幅、半身）按款依次保存：同一款连续操作时，后一次在前一次保存完成后再发，界面以最后一次操作为准，不会被先到的旧结果覆盖。
- 半身标记连点两次 = 加上再去掉，结果与点击次数一致。
- 保存失败时界面恢复到保存前的状态，并出 toast 说明原因。

## 5. run 节点图页

- 换装范围单选改成分段控件；引擎下拉改成分段控件；`confirm` 改成工作表；报错改成 toast。
- 成图节点上的勾选改成点卡片选中（选中有勾标与边框），右上角保留勾选标记方便看清；「全选」按钮保留。
- 底栏「重出」与「取消」样式与合集页底栏一致；重出中显示进度。
- 空格快速预览、Esc 关闭弹层与合集页一致。
- 带 item 的组仍只读，「在合集里重出」链接保留。

## 6. 范围外

- 配色、字体、整体版式改版；深色模式。
- 引入前端框架、组件库或构建步骤；改动 Studio 看板（`ui/app.js`）。
- 任何业务规则、接口、文件命名、运行记录格式的变化（合集页 spec 照旧）。
- 自动质检、自动评分、自动识别半身。
- 手机 / 触屏专门适配（桌面浏览器为准，窄窗口不出横向滚动即可）。
- 跨进程同时写合集设置（Fable 审核第 8 条，只记录）。

## 7. 验收标准

1. 合集页、run 节点图页不再出现原生 `<select>`、设置类复选框（「选这款出图」与成图勾选除外）、`alert`、`confirm`。
2. 搭配规则、换装范围、统一范围、引擎、模式都是分段控件，点选与键盘（← / →）都能切换，结果与改造前选下拉一致（保存的设置、出图计划相同）。
3. 保持画幅、全部保持画幅是开关；切换后出图提示词末尾是否含固定句子与改造前一致。
4. 固定模特 / 一对一抽屉里，点参考图弹出带缩略图的菜单，选中后该衣服的参考图变化，出图计划里 `itemRefs` 对应变化。
5. 拖动组头能改款顺序，刷新后顺序保持；「…」菜单的移到最前 / 最后可用。
6. apimart 出图、替换裁图、停止出图、恢复默认都出工作表确认；回车确认（焦点在「取消」上时回车 = 取消）、Esc 取消；取消后什么都不发生。
7. 放图成功 / 失败、保存失败、出图开始与结束都有 toast；出错的 toast 不自动消失。
8. 合集页出图中底栏显示「出图中 N/M」与停止；停止后该 run 状态为已取消，已交付的图保留。
9. 快速预览：选中缩略图按空格打开，← / → 切换，空格或 Esc 关闭；成图对照里 ← / → 切换版本。
10. ⌘F 聚焦搜索，⌘↩ 出图；所有弹层（抽屉、待重出、对照、预览、工作表、弹出菜单）都能 Esc 关闭。
11. 同一款快速连续改设置（含连点半身两次），刷新后结果与最后一次操作一致；保存失败时界面回到保存前。
12. 上传中往同款另一栏放图会排队放入，不丢文件，也不覆盖已有文件。
13. 缩略图大小滑块可调，刷新后保持。
14. 开启系统「减少动态效果」后页面无过渡动画，功能不受影响。
15. 合集页 spec 第 11 节的验收条目全部仍然通过；全量 `npm run build && npm test && npm run typecheck && npm run scan:secrets` 通过。
16. 同事包能照常打包，清单只因新增前端文件而变化。
