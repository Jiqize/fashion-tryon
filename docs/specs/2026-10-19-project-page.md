# 项目页：一个素材目录一个项目

- 状态：已确认（2026-10-19）
- 日期：2026-10-19
- 基于：合集页（`docs/specs/2026-10-15-collection-page.md`）、前端交互升级（`docs/specs/2026-10-16-frontend-interaction.md`）、一键启动 `fashion-tryon open`（`ab152ed`）
- 不取代：文件夹仍是唯一事实来源；合集页、run 节点图、出图、MCP 工具的行为不变

## 1. 背景与目标

现在一个合集页对应一个素材根目录，启动器只记得上次那一个。做的批次多了以后，要么所有款堆进同一个目录越来越乱，要么每次按住 Option 重新选目录，看不到「手上有哪些批次、各做到哪」。

目标：

1. 新增「项目页」：一个项目就是一个素材根目录，一页列出全部项目，点进去就是这个目录的合集页。
2. 每个项目卡片一眼看到封面、款数、成图数、最近出图时间、待重出数量。
3. 在项目页里加入已有文件夹或新建文件夹，改显示名、从列表移除、在 Finder 里打开。
4. 合集页能回到项目页；启动器和 `fashion-tryon open` 默认打开项目页。

## 2. 入口

- 双击「Tryon 合集」启动器，或运行不带参数的 `fashion-tryon open`，打开项目页。项目页服务在跑就复用，没在跑就在后台拉起，不会自动退出。
- `fashion-tryon open <素材根目录>` 仍然直接打开该目录的合集页，同时把它加入项目列表（已在列表里就不重复加）。
- 启动器不再需要按住 Option 选目录；选目录改在项目页里做。
- MCP `open_graph`、CLI `editor` 行为不变（直接打开指定目录的合集页或 run 节点图），也把该目录加入项目列表。
- 合集页顶栏最左边加「项目」入口，回到项目页；顶栏原来的「合集 · 目录名」显示改为项目的显示名。

## 3. 项目列表

- 项目列表按本机保存（`~/.config/fashion-tryon/projects.json`，与 `last-root` 同目录），不写进任何素材目录。
- 第一次打开项目页时，如果有记住的上次目录（`last-root`），自动把它作为第一个项目。
- 每个项目记录：素材根目录的绝对路径、显示名（默认是文件夹名）、加入时间。
- 同一个文件夹（按解析后的绝对路径判断）只出现一次。

## 4. 项目卡片

项目页是卡片网格，最后一张是「＋ 新建项目」。每张卡片显示：

| 内容 | 规则 |
|---|---|
| 封面图 | 最近一次交付的成图；没有成图时用第一款的第一张衣服图；都没有显示空白占位 |
| 显示名 | 默认文件夹名，可改 |
| 款数 · 成图数 | 款数与合集页一致；成图数是 `成图/<款号>/` 下的图片数（含各版本，不含 `_runs/`） |
| 最近出图 | 最近一次出图的开始时间，例如「10-16 14:32」；从没出过图显示「还没出图」 |
| 待重出 | 待重出清单有内容时显示「待重出 N」，没有不显示 |

- 卡片按「最近出图」从新到旧排序；没出过图的按加入时间从新到旧排在后面。
- 点卡片进入该项目的合集页（同一个浏览器标签页）；该目录的编辑服务在跑就复用，否则拉起，与现在的 `open` 一样。
- 打开项目页或点「刷新」时重新统计；不做实时刷新。
- 文件夹已经不存在（被移走或删掉）时，卡片变灰，显示「找不到文件夹」和原路径，不能进入，只能「从列表移除」。

## 5. 新建与加入项目

- 点「＋ 新建项目」弹出 macOS 的选文件夹窗口：可以选已有文件夹，也可以用窗口里的「新建文件夹」建一个空文件夹再选它。取消就什么都不做。
- 选中的文件夹已在列表里：不重复加，直接进入它的合集页。
- 选中后加入列表并直接进入它的合集页；空文件夹在合集页里用「新建款」开始放图（与现在一致）。
- 不检查文件夹里有没有 服装 / 模特 目录；扫不出款就是 0 款。
- 不允许选磁盘根目录或用户主目录本身（提示「请选一个具体的素材文件夹」）。

## 6. 管理项目

每张卡片右上角「…」菜单：

- **改显示名**：只改项目页和合集页顶栏上显示的名字，不改文件夹名；不能为空，最长 40 字。清空恢复为文件夹名。
- **在 Finder 里打开**：打开这个素材根目录。
- **从列表移除**：确认工作表「只从项目页移除，不删除文件夹里的任何文件」，回车确认、Esc 取消；移除后 toast 可撤销。该目录的编辑服务如果在跑，不受影响。

## 7. 视觉与交互

- 沿用合集页的极简风格和共享控件（菜单、工作表、toast），不引入新样式体系。
- 卡片网格随窗口宽度自动换行，窄窗口至少一列。
- 快捷键：⌘F 聚焦搜索；在搜索框里按项目显示名或文件夹名过滤（不区分大小写）。
- 项目页只监听 `127.0.0.1`，鉴权、Origin、CSP 与编辑服务一致；页面上不显示完整路径以外的本机信息。

## 8. Out of Scope

- 一个素材目录里再分多个项目、给款打项目标签、跨项目移动款。
- 在项目页里重命名、移动、删除文件夹或其中的文件。
- 项目页上直接出图、显示出图进度、显示每款详情。
- 项目归档 / 分组 / 置顶、自定义封面。
- 多台电脑之间同步项目列表。
- 合集页、run 节点图、出图规则、MCP 工具参数的任何改动（除第 2 节的「项目」入口和显示名）。

## 9. 验收标准

1. 双击启动器（或 `fashion-tryon open`）打开项目页；已有 `last-root` 时它作为第一个项目出现。
2. 卡片显示封面、显示名、款数 · 成图数、最近出图时间；有待重出时显示「待重出 N」；数字与进入后合集页一致。
3. 卡片按最近出图从新到旧排序，没出过图的排后面。
4. 「＋ 新建项目」选已有文件夹 → 加入列表并进入它的合集页；在窗口里新建空文件夹 → 进入 0 款的合集页，放图后返回项目页能看到款数变化；选已在列表里的文件夹不重复加。
5. 合集页顶栏「项目」回到项目页；顶栏显示项目的显示名。
6. 改显示名后项目页和合集页都显示新名字，文件夹名不变；清空恢复文件夹名。
7. 「在 Finder 里打开」打开对应文件夹；「从列表移除」确认后卡片消失，toast 撤销能恢复，文件夹里文件一个不少。
8. 把一个项目的文件夹移走后刷新项目页，卡片显示「找不到文件夹」且只能移除。
9. `fashion-tryon open <目录>`、`open_graph`、`editor` 打开的目录自动出现在项目页。
10. 同时打开两个项目的合集页，各自出图互不影响（各自的锁、进度、待重出）。
11. 项目页鉴权、Origin、CSP 有测试；除封面缩略图缓存（`成图/_runs/.thumbs/`，与合集页同一处）外，不往任何素材目录写入文件。
12. 真实验收：在本机用现有 `~/Documents/AI` 和一个新建空文件夹走一遍，交用户目测。

## 10. 已定事项（2026-10-19 确认）

- 一个项目就是一个素材根目录；项目列表只存本机，不写进素材目录。
- 启动器和不带参数的 `fashion-tryon open` 默认打开项目页，不再直接进上次的合集页。
- 卡片按「最近出图」从新到旧排序，不做手动拖动排序。
- 新建项目用 macOS 选文件夹窗口（可在窗口里新建文件夹）。
- 管理只做改显示名、在 Finder 里打开、从列表移除（可撤销）。
