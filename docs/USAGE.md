# Fashion Try-on Studio 使用说明

一批素材通常 30–40 套、每套 3–8 张姿势。整批只需要三类人工动作：确认开始、按套判断、（可选）重出。生成和判断同时进行，一套判完即交付。

## 一句话开始

~~~text
请用 fashion-tryon 处理 /绝对路径/本次素材
~~~

Agent 会在后台运行 `fashion-tryon studio /绝对路径/本次素材` 并把页面地址给你。之后不需要再回对话授权或"保存/应用"，页面上的每个判断直接写入运行记录。想知道进度时可以让 Agent 查 `fashion-tryon status`。

开始新的一批：把另一个素材根目录交给 Agent，它会另起一个 `studio` 进程。浏览器拿不到本地文件夹的绝对路径，所以不支持在页面里拖入目录。

## 用 MCP 出图（精简流程）

注册方法和各工具见 README 的“MCP”一节。装好后直接对 Agent 说“用 fashion-tryon 给 /绝对路径/本次素材 出图”：Agent 会扫描、看图写裁切方案并裁图、后台开始出图，并在浏览器打开可编辑节点图（地址由本机编辑服务提供，只监听 `127.0.0.1`）。

- 节点图每款一条泳道：服装参考图 → 提示词 → 每张“模特图 → 成图”，状态为 排队 / 生成中 / 已完成 / 失败 / 已取消；点图片放大，模特图与成图并排。
- 同一素材目录同时只跑一个出图；让 Agent “取消出图”时，正在出的那张放弃，已交付的保留。
- 出图进程意外退出后显示“已中断”，让 Agent 指定款号重新出图即可，已交付的图不会被覆盖。

### 在节点图里改参数并重出

- 打开方式：出图开始后自动打开；之后要再打开，让 Agent 调 `open_graph` 并给 runId；不给 runId 或运行 `fashion-tryon editor <素材根目录>` 打开的是合集页。直接双击 `graph.html` 是只读页面，看得到全部状态，但没有编辑入口。
- 固定模特、一对一的出图组合在节点图里每个组合一条泳道，标题为「<款号> · <衣服图名>」，只读显示参考图、提示词、模特和成图，没有编辑和勾选；标题旁「在合集里重出」进入合集页修改和重出。有追加提示词（半身、待重出备注）的成图下方小字显示「追加：…」。
- 每款标题旁点「编辑」展开面板：
  - **参考图**：拖动缩略图调整顺序（键盘可用图上的 ↑↓）；从下方「可添加」区（原图、`裁图/<款号>/`）拖进列表即加入，或点 `+`；拖出列表或点 `×` 移除（只是这次不用，不删文件）；可改用途名。鼠标移到图上出现 ✂，在图上拉框、填用途名后保存，写入 `裁图/<款号>/`，同用途已有裁图时先问是否替换。参考图不能超过上限（默认 6 张）。
  - **提示词**：可直接改，改过标「已改」，点「恢复默认」回到自动生成的提示词。没改过时随参考图和换装范围自动更新；改过后再动参考图会提示「参考图已变，提示词里的图号可能对不上」，不会自动覆盖。
  - **换装范围**：每款用分段控件单独选「换整套」或「只换上衣」。
  - **模特图**：在面板最上方，点缩略图选中或取消；列出这款模特图目录里的全部图，新放进去的刷新页面后出现，也可以勾选出图。
- 点成图卡片选中要重出的图（选中的卡片显示勾标；选中后按空格快速预览），或用面板里的「全选」，底部点「重出」：只出勾选的图，新建一次出图，页面跳到新出图，页头显示「来自 <runId>」可跳回。交付同样写进 `成图/<款号>/`，同名加 `-v2`、`-v3`，从不覆盖。
- 人工改的提示词只用于这一次重出，以后的出图仍用默认提示词。
- 引擎在底栏的分段控件里选，默认 codex；选 apimart 重出会弹出工作表确认费用（回车确认、Esc 取消）。有出图在跑时「重出」不可用，底栏显示「出图中 N/M」与进度条；正在跑的那次出图页面上有「取消」，同样先确认。出错以 toast 提示，不自动消失。
- 参考图带模特的脸会把成图带偏：先拖框裁掉脸，再只重出那一张。在对话里也可以让 Agent 用 `rerun` 只重出一张。

### 项目页

- 一个项目就是一个素材根目录。**一键打开**：`npm run install:launcher` 安装「Tryon 合集」到 `~/Applications`，桌面放替身；双击打开项目页，服务在跑就复用，没在跑就在后台拉起（不会自动退出）。命令行等价于 `fashion-tryon open`；`fashion-tryon open <素材根目录>` 直接打开该目录的合集页。换了 node 或仓库位置后重新安装一次。
- 每张卡片：封面（最近一次交付的成图，没有就用第一款的第一张衣服图）、显示名、「N 款 · M 张成图」、最近出图时间（没出过显示「还没出图」）、有待重出时「待重出 N」。按最近出图从新到旧排，没出过图的按加入时间排在后面。打开页面或点「刷新」时重新统计；⌘F 搜索显示名或文件夹名。
- 点卡片进入该目录的合集页；合集页顶栏最左边「项目」回到项目页，顶栏显示项目的显示名。
- 「＋ 新建项目」弹出系统选文件夹窗口：选已有文件夹，或在窗口里「新建文件夹」再选它；已在列表里的不重复加，直接进入。不能选磁盘根目录或用户主目录本身。
- 卡片右上角「…」：改显示名（只改显示，不改文件夹名；清空恢复文件夹名，最长 40 字）、在 Finder 里打开、从列表移除（只从项目页移除，不删任何文件，toast 可撤销）。文件夹被移走或删掉后卡片变灰，显示「找不到文件夹」，只能移除。
- 项目列表只存本机 `~/.config/fashion-tryon/projects.json`，不写进素材目录；`fashion-tryon open <目录>`、`open_graph`、`fashion-tryon editor` 打开过的目录自动加入。第一次打开时，上次记住的目录（`last-root`）自动成为第一个项目。

### 在合集页放图并出图

- 节点图页头点「合集」进入；`open_graph` 不给 runId、或 `fashion-tryon editor <素材根目录>` 直接打开合集页。
- 一款一组，左边衣服、右边模特。顶栏：「项目」（回项目页）、项目显示名与款数、模式分段控件（放图 / 节点，浏览器记住上次的选择）、搜索款号、缩略图大小滑块（浏览器记住）、刷新、新建款、「按款号排序」。组头有搭配规则、换装范围两个分段控件和「保持画幅」开关（← / → 可切换分段）。拖动组头的序号调整款的顺序，或点组头「…」菜单选「移到最前」「移到最后」「折叠 / 展开」；顺序按素材目录保存，折叠状态在浏览器里记住，折叠后显示一行摘要。
- 快捷键：⌘F 聚焦搜索，⌘↩ 出图；选中缩略图按空格快速预览（← / → 切换，空格或 Esc 关闭）；抽屉、待重出、对照、预览、确认工作表、弹出菜单都可按 Esc 关闭。确认类操作（apimart 出图、替换裁图、停止出图、恢复默认）都弹出工作表，回车确认、Esc 取消；放图、保存、出图开始与结束的结果用 toast 提示，出错的 toast 不自动消失。
- **放图模式**：每款一张卡片，左栏衣服、右栏模特。把电脑里的图拖进放置区，或点放置区选文件（可多选），显示「正在放入 x / y」，放完卡片立即刷新，并列出成功几张、哪些没放进去及原因；放图时仍可勾选、编辑别的内容，只有「出图」要等放完。卡片底部一行是这款每个出图组合的最新成图。
- **节点模式**：每款一条流程：衣服节点 → 设置节点（换装范围、搭配规则、参考图张数、提示词默认 / 已改、画幅）→ 每个出图组合一行（模特或「衣服 + 模特」→ 成图历次版本，最新的最大；生成中、排队、失败分别标出）。点模特节点切换这一行出不出。
- **搭配规则**（每款一种，默认固定服装）：

  | 规则 | 左边的含义 | 生成 | 例子 | 成图命名 |
  | --- | --- | --- | --- | --- |
  | 固定服装 | 同一套衣服的多张参考图 | 每个选中的模特 × 整套参考图 | 左 ABCD、右 EFG → 3 张 | `成图/<款号>/<模特图名>.png` |
  | 固定模特 | 多件单品，每张图一件 | 每张选中的衣服图 × 唯一选中的模特 | 左 A–G、右 X → 7 张 | `成图/<款号>/<衣服图名>-<模特图名>.png` |
  | 一对一 | 与右边按顺序配对 | 第 n 张衣服图 × 第 n 张选中的模特图 | 左 ABC、右 EFG → AE、BF、CG | `成图/<款号>/<衣服图名>-<模特图名>.png` |

  - 固定模特下右边必须正好选中 1 个模特，否则提示「固定模特只能选 1 个模特」，这款不出图。一对一两边张数不同时，多出的图标「未配对」，不出图。
  - 固定模特、一对一下点衣服缩略图切换选中；每件衣服只用一张参考图，裁过的默认用裁图，在编辑抽屉里点该衣服的参考图，从带缩略图的弹出菜单改选哪张裁图或改回原图。
  - 重出加 `-v2`、`-v3`，一律不覆盖。从未在页面设置过的款按固定服装，与 `start_run` 默认完全一致。
- **保持画幅与半身**：开「保持画幅」后提示词末尾追加「保持图1的取景范围，被截掉、没拍到的身体部位不要补画。」；模特缩略图标「半身」的，出图时总是加这句。不做任何自动检测。搭配规则、保持画幅、半身标记保存在 `成图/_runs/collection.json`，重新打开仍在。
  - 只收 jpg / jpeg / png / webp，单张不超过 50 MB；heic、gif、pdf 等不放入，也不自动转换。
  - 沿用素材目录现有的结构（按款分目录或按角色分目录）；新目录用 `<款号>/服装/`、`<款号>/模特/`。
  - 文件名保留原名，同名自动加 `(2)`、`(3)`，从不覆盖。
  - 裁图在衣服栏、模特栏下面单独一排（在「成图」上面，带「裁」标，默认按文件名，可拖动排序；固定服装的默认参考图按这一排的顺序）；出图实际用的参考图（原图或裁图）描绿边。裁图不会自动生成，要点「裁图」或让 Agent 写裁切方案。
  - 衣服图、模特图、成图悬停时左上角出现 ×，点了移到 `成图/_runs/已删除/<款号>/`，底部 toast 点「撤销」可放回；出图中不能删。衣服图连同它的裁图一起移走；成图只删当前显示的这个版本，同时移出待重出清单（撤销不加回）。
  - 衣服、模特图可在栏内拖动排序，顺序按素材目录保存；一对一按这个顺序配对（第 1 件衣服配第 1 个模特）。页面上出图和让 Agent 用 `start_run` 出图都按这个顺序。
  - 在 Finder 里新放的图点「刷新」后出现，与页面放入的没有区别。
- 「新建款」：填款号（不能为空，不能含 `/`、`\`、`_`、空格，不能与已有款号重复），出现空白卡片后往里放图。没放图的新款不写入文件夹，重新打开页面后消失。
- 出图：勾选要出的款（缺服装图或模特图的款不能勾），点「编辑」在右侧抽屉里改参考图、换装范围、搭配规则、保持画幅、提示词，「恢复默认」回到默认；点模特缩略图挑图（默认全选）。底栏显示已选几款、共出几张，可用分段控件统一换装范围（按各款设置 / 全部换整套 / 全部只换上衣）、用开关全部保持画幅（只作用于这次，不改各款保存的设置）；点「出图」把勾选的款合成一次出图，「只出这款」只出该款。出图中底栏主按钮显示「出图中 N/M」与进度条，旁边的「停止」确认后取消这次出图，已交付的图保留；结束后自动刷新成图。未编辑的款与 `start_run` 默认规则相同（有裁图用裁图，取前 6 张）。引擎在底栏分段控件里选，默认 codex，选 apimart 需在工作表里确认费用；同一时间只允许一次出图。
- **成图对照与待重出**：双击成图（或悬停点「对照」）打开对照，左边是服装图（这次出图实际用的参考图，固定服装有几张就排几张），中间是成图，右边是模特图，用分段控件或 ← / → 切换版本；「加入待重出」「出图记录」「关闭」。已在待重出的成图，按钮变成「移出待重出」，再点一下就移出。待重出清单在侧边面板里跨款收集，每项可填一行备注、可移除（移除后 toast 上点「撤销」可恢复），按素材目录保存；「重出这 N 张」按产出它的那次出图的参考图、范围、提示词重出，备注追加到提示词末尾，N 张合成一次新出图，提交后清单清空。有出图在跑时「出图」「重出这 N 张」都不可用。Finder 里手放、没有出图记录的成图也显示，但没有「出图记录」入口。
- 页面里的小图都是缩略图（长边 320），第一次显示时生成，缓存在 `成图/_runs/.thumbs/`，原图改了会自动重新生成；可以随时删掉这个目录。裁图框和成图对照显示原图。

下面是 studio 看板的说明。

## 1. 准备素材

~~~text
本次素材/                     # 素材根目录（只读）
├── EK52338_灰色套装/         # 一套；第一个 _ 或空格前是款号
│   ├── 服装/
│   │   └── 01.jpg
│   └── 模特/
│       ├── 01.jpg
│       ├── 02.jpg
│       └── 03.jpg
└── EK52339/
    ├── 服装/
    └── 模特/
~~~

- 支持 `.jpg` `.jpeg` `.png` `.webp`；`._*`、`.DS_Store` 等系统文件自动跳过。
- 角色目录也识别 `衣服`、`单品`、`garment`、`人物`、`model` 等写法。
- 模特图张数超出 3–8 只提示，不阻止；固定模特模式不提示。
- 素材目录只读；唯一会写入的是 `成图/`，扫描时忽略它。

## 2. 开跑前：素材表

页面主体是一张"套 × 图"表：每行一套，最左侧是服装裁后图，右侧依次是这套的模特图。

- **裁切**：每套服装自动定位裁切。选中后按 `C` 手动拖动裁切框，`Enter` 保存，`Backspace` 恢复自动裁切，`Esc` 取消；只作用于本批。
- **提示词**：按 `E` 展开这一行的服装描述与提示词，只供查看，不需要确认。
- **准备失败**：自动裁切、服装描述或提示词生成失败的套，服装图下显示失败原因，点这一行的"重新准备"重试；也可以手动裁切来恢复。
- **设置条**：搭配模式、换装范围（全身 / 上装 / 下装 / 含配饰）、每张候选数（1–4，默认 1）、并发数（默认 5，上限 10）。单套可以单独改模式与范围。
- **确认开始**：顶部显示"共 X 套、Y 张任务、Z 次生成、预计约 ¥W"，点"开始"（或在设置条里按 `Enter`）。可以只勾选部分套，之后再追加。

### 搭配模式

| 模式 | 一套内的素材 | 产出 |
| --- | --- | --- |
| 固定服装（默认） | 1 张服装 + N 张模特姿势 | N 张，每个姿势一张 |
| 一对一 | N 张服装 + N 张模特 | N 张，按文件顺序配对 |
| 固定模特 | N 张服装 + 1 张模特 | N 张，每件衣服一张 |

数量不符合模式（一对一两边张数不同、任一边为空）的套标为"素材不全"，不进入生成，其他套照常进行。

## 3. 生成

- 按套优先：先把已开始的套做完，让整套尽早可以判断。
- 每行实时显示排队 / 生成中 / 已完成 / 失败及原因；失败的图可以单独重试，也可以点"重试所有失败"；不想要的失败图按 `X` 标记不交付，这套其余的图照常通过。
- 可以暂停和继续；运行中也能调整并发数。
- 遇到服务商限流会自动降低并发、延后重试，不会重复计费。
- 进程崩溃或关机后，重新运行同一条 `studio` 命令：已经提交给服务商的任务只继续取结果，不会重新提交；已做的判断不丢失。

## 4. 判断

一套的所有图都有结果后，这一行进入"待判断"，同时其他套继续生成。

- **默认通过**：在一行上按 `Enter`，这套里未标记的图全部采用并立即交付。
- **标记例外**：选中某张图，按 `R` 重出或 `X` 不交付。
- **重出**：按 `R` 弹出问题标签（颜色偏、多了配饰、少了单品、下装被换、姿势变了、人物变了、角色互换、其他），数字键多选，`Tab` 补一句说明，`Enter` 确认后立即排队，不需要再授权。新结果回到同一格，历史版本保留、可用数字键切换。
- **多候选**：候选数大于 1 时，用 `1`–`4` 在候选之间选择；不选默认采用第一张。
- **对照**：按 `Space` 打开三栏对照（服装裁后图、模特原图、成图），点击任意一张同步放大、移动鼠标同步平移。
- **撤销**：`⌘Z`（Windows 为 `Ctrl+Z`）撤销最近一次判断操作；已提交的重出不可撤销。
- **撤回交付**：已交付的套可以撤回后重新判断；撤回只改本批记录，`成图/` 里已写出的文件保留。

顶部显示整批进度："已交付 a 套 / 待判断 b 套 / 生成中 c 套 / 失败 d 张"。

### 全部快捷键

| 按键 | 作用 |
| --- | --- |
| `↑` / `↓` | 切换套 |
| `←` / `→` | 切换同套内的图 |
| `Enter` | 整套通过；设置条内等于"开始"；弹窗内等于确认 |
| `R` | 重出（弹出问题标签） |
| `1`–`8` | 重出弹窗内多选问题标签 |
| `Tab` | 重出弹窗内写说明 |
| `X` | 标记 / 取消不交付 |
| `1`–`4` | 切换候选或历史版本 |
| `Space` | 打开 / 关闭放大对照 |
| `E` | 展开提示词 |
| `C` | 调整服装裁切框 |
| `Backspace` | 裁切框内恢复自动裁切 |
| `Esc` | 关闭弹窗、对照或裁切框 |
| `⌘Z` / `Ctrl+Z` | 撤销最近一次判断 |

## 5. 交付

- 一套判断完成（每张图都已采用或标记不交付，且没有排队中的重出）后，自动发布到 `<素材根目录>/成图/<款号>/`。
- 文件名为 `<款号>_<模特图文件名（不含扩展名）>`（固定模特模式用服装图文件名）；同名文件不覆盖，自动加 `_2`、`_3`；内容相同的文件不重复写入。
- 不交付的图和未采用的版本不会进入 `成图/`。
- 批次目录里的 `总览.html`（每套一行缩略图 + 映射表）与 `mapping.csv` 随每次交付更新，可以直接发给同事。

## 批次目录

~~~text
<素材根目录的父目录>/<素材根目录名>-tryon-studio/
├── studio.json     # 唯一运行记录：设置、套、素材、任务、全部版本与判断
├── prepared/       # 服装裁后图与压缩后的工作副本
├── images/         # 全部生成版本（不覆盖）
├── thumbs/         # 页面缩略图缓存
├── 总览.html
└── mapping.csv
~~~

同一批同一时间只允许一个 `studio` 进程；第二个会被拒绝。

## 命令参考

~~~bash
fashion-tryon studio <素材根目录> [--port <n>] [--no-open] [--json]
fashion-tryon status <素材根目录> --json
~~~

`studio` 首行输出 `{ "url": ..., "batchDir": ... }` 后常驻，收到 Ctrl+C 退出。`status` 不加锁、只读 `studio.json`，服务运行中也能查询；批次尚未创建时返回 `NOT_FOUND`。
